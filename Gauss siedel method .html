🔢 Gauss-Seidel Solver

Interactive solver for systems of linear equations Ax = b

Step 1: Set Matrix Dimensions

Enter the size of your square matrix (2-10). For example, 3 creates a 3×3 matrix for solving 3 equations with 3 unknowns.

Step 2: Enter Coefficient Matrix (A) and Constants Vector (b)

System format: Ax = b, where A is the coefficient matrix and b is the constants vector

Step 3: Set Solver Parameters

Max Iterations: Maximum number of iterations before stopping.
Tolerance: Convergence criterion. Algorithm stops when ||xk - xk-1|| < ε
